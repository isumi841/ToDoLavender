# Android Todo App

A simple Android Todo application developed using Java and SQLite in Android Studio.

## Features

- User Registration
- User Login
- Forgot Password
- Add New Task
- Edit Task
- Delete Task
- Mark Task as Completed
- Local SQLite Database

## Technologies Used

- Java
- Android Studio
- SQLite
- Git
- GitHub
